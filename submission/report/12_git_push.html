GitHub • Push và xác minh ba nhánh

Báo cáo từ mã và nhật ký chạy thực tế · 2026-09-14 20:19

Đã push thành công master, example, example2. Kiểm tra bằng ls-remote: hash từng nhánh trên GitHub khớp chính xác với local.

$ git ls-remote --heads origin
207118990d9f858c4b259a42e2d353753ecf58a3	refs/heads/example
1b1aaeed80441e51d0b73a58a4a5918afcd97527	refs/heads/example2
92b65cee4b997b0833b82f98ff036e00603cc6bd	refs/heads/master

$ git branch -vv
  example  2071189 [origin/example] Add example line on example branch
* example2 1b1aaee [origin/example2] Merge example into example2
  master   92b65ce [origin/master] Add tmp.txt greeting
