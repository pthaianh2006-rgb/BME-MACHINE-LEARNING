Git • Add, commit và phiên bản cũ

Báo cáo từ mã và nhật ký chạy thực tế · 2026-09-14 20:24

$ git status --short
?? tmp.txt

$ git add tmp.txt
$ git status --short
A  tmp.txt

$ git commit -m Add tmp.txt greeting
[master 92b65ce] Add tmp.txt greeting
 1 file changed, 1 insertion(+)
 create mode 100644 tmp.txt

$ git checkout --detach e0ac946683873bd23da5180ca7fb03915991445d
HEAD is now at e0ac946 Initial commit

$ Observation
At initial commit: tmp.txt exists = False; README.md and .gitignore remain.
Trước add: ?? tmp.txt (untracked). Sau add: A  tmp.txt (staged). Checkout initial commit làm tmp.txt biến mất vì phiên bản này chưa có file đó. Để cập nhật remote: add → commit → push. Checkout đơn thuần không cập nhật remote.
